# Jetcut

Jetcut is a URL shortener built with Next.js.

## Features

- Shorten anonymous links that last for 48 hours.
- Links created with an account will last for 30 days.

## Technology Stack

- NextJs
- Postgres & Prisma
- Auth.js

## Development

You can use the flake or the dev container to automatically set up the development environment. The dev container is recommended.
